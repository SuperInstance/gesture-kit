gesture-kit

A gesture is a path through some abstraction space. Its geometry — how far it travels, how hard it turns within a plane (bend), and how much it turns out of that plane (twist) — says what a snapshot can't. Each hull below is coloured by local stress: blue is calm, red is taut. The property is in the twist.

a rising line

Straight travel: arc, no bend, no twist.

an arch (planar)

Bends hard, but stays in one plane — twist ≈ 0.

a helix (leaves the plane)

Same turning, but each turn opens a new axis — twist > 0.

a lurching walk

Restless: high bend, red segments where it whips around.
